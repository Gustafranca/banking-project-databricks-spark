# banking-project-databricks-spark

Context: Banks generates large volumes of data from core banking systems, payumens getways, and exeternal credit bureaus. Data in this comapny is across multiple platforms and formats, making unified analytics dificult.

Some problems to be solved: 
- Banking data exists in multiple disconnected sources, creating data silos.
- Manual pipelines make data processing slow, complex and hard to scale.
- Businesse user lack self service analytics for operational and risk insights.

How to solve:
- Build a metadata-driven framework on Databricks using Medallion Architecture (Bronze, Silver, Gold).
- Integrates SQL Server and cloud storage data sources into a unifies analytics plataform
- Created interactive dashboards and AI interface for business user to query data easily.
